# Proyek Pemrograman Mobile

## Deskripsi
Aplikasi latihan untuk praktikum Pemrograman Berbasis Mobile.

## Pengembang
Nama panggilan / akun GitHub: Rossiadiadiutama / rozz030

## Tujuan
Proyek ini bertujuan untuk mempelajari pengembangan aplikasi mobile menggunakan Flutter serta memahami penggunaan Git dan GitHub dalam pengelolaan proyek.

## Rencana Fitur
1. Tampilan antarmuka aplikasi mobile.
2. Navigasi antarhalaman.
3. Pengelolaan dan penyajian data pada aplikasi.

## Cara Menjalankan
1. Pastikan Flutter sudah terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan perintah `flutter pub get`.
4. Jalankan aplikasi dengan perintah `flutter run`.
